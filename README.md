# TicTacToeGame

TicTacToe game made in Angular 20 to practice more about components, services, state and comunication between components.

---

## Overview

- Users will be able to choose to play between another player or cpu
- Users will be able to choose if they play with cross or circle
- See score between cross, circle or draw game
